# Nädal 5: Andmete analüüs ja SQLi kasutamine

## Mis selle nädalaga õppisin?

- SQL päringute koostamine ja testimine

- Tabeliandmete analüüsimine ja tulemuste kokkuvõte
- Portfoolio sissekandmisega seotud dokumentatsiooni täiustamine

## Näide kasutatud SQL-ist

```sql
SELECT *
FROM team_members
WHERE week >= 5
ORDER BY joined_at DESC;
```
